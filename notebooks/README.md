# SQL Analysis Notebooks

This folder contains two Jupyter notebooks analyzing Chicago public datasets using SQL, Python, Pandas, and SQLite.

## 1. Chicago Public Schools SQL Analysis

[View Notebook](Chicago_Public_Schools_SQL_Analysis.ipynb)

Examines school attendance, safety scores, college enrollment, and community-level differences using SQL queries.

**SQL techniques:** Filtering, sorting, aggregation, subqueries, and joins.

## 2. Chicago Census, Crime, and Schools SQL Analysis

[View Notebook](Chicago_Census_Crime_Schools_SQL_Analysis_With_Data_Sources.ipynb)

Explores community poverty, socioeconomic hardship, school safety, and recorded crime incidents using three related Chicago datasets.

**SQL techniques:** Filtering, grouping, aggregation, distinct values, and nested queries.
